# Meghana Nagaraj — Personal Portfolio Website

A modern, responsive, and visually polished developer portfolio built with **React**, **Vite**, and custom **CSS**, designed following the **UI/UX Pro Max** design system.

## ✨ Features

- **OLED Dark Theme & Aurora Accents**: High-contrast, accessibility-first color palette with subtle mesh gradients and glassmorphism cards.
- **Responsive Layout**: Designed and optimized for mobile devices, tablets, laptops, and ultra-wide screens.
- **Interactive Navigation**: Sticky backdrop-filter header with smooth section scrolling, active scroll-spy indicators, and mobile drawer menu.
- **Sections Included**:
  - **Hero / Home**: Headline, status indicator, interactive macOS-style developer profile preview, and quick social links.
  - **About Me**: Narrative story of a first-year engineering student, quick stats bento grid, and core engineering pillars.
  - **Skills**: Filterable categories (*Languages*, *Web & Frameworks*, *Developer Tools*, *CS Fundamentals*) with proficiency tags.
  - **Projects**: Portfolio cards with live demo and GitHub links, feature bullet points, and tech stack tags.
  - **Education**: Timeline detailing engineering coursework, academic distinctions, and independent study.
  - **Contact**: Interactive contact form with state feedback, direct social channels, and a one-click **Copy Email** button.
  - **Footer**: Quick navigation links, social buttons, and a smooth **Back to Top** button.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Vanilla CSS (Variables, Flexbox, CSS Grid, Glassmorphism, Micro-animations)
- **Icons**: Lucide React & Custom SVG Social Icons
- **Typography**: Google Fonts (*Plus Jakarta Sans* & *JetBrains Mono*)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/meghana123000-ui/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```

---

## 📝 Customizing Your Information

All your personal details, skills, projects, and education history are neatly organized in a single configuration file:
👉 **`src/data/portfolioData.js`**

To update your projects, add new skills, or change social links, simply edit this file and the changes will reflect across the site instantly.
